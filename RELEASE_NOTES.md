## GatorSqoosh 1.2.0

- Custom mountain icon in the app, Windows executable, macOS app bundle, and Dock.
- Light, dark, and system themes with teal gradients.
- Themed Windows title bar with native minimize, maximize, and close controls.
- Optional maximum output size for each image. Quality is reduced first, followed by dimensions when needed. Oversized results are not saved.
- Recursive folder compression with full-folder copy, images-only, and in-place modes.

### Downloads

- Windows x64: extract the ZIP and run `GatorSqoosh.exe`.
- macOS Apple Silicon: use the `mac-arm64` DMG or ZIP.
- macOS Intel: use the `mac-x64` DMG or ZIP.

All release packages pass desktop export, folder-mode, theme, title-bar, and file-size-limit tests on their matching OS and architecture before publication. Packages are unsigned and macOS packages are not notarized; downloaded apps may require approval in system security settings.
